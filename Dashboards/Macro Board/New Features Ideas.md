# Macro Board feature ideas

These are possibilities, not committed requirements. GitHub issues and the Project board are the source of truth for active work; create or link an issue before implementation.

## Navigation and organization

- Multiple pages for work, gaming, media, and other profiles.
- Search or a `Ctrl+K` command palette for larger boards.
- Drag-and-drop ordering, recent actions, and favorites.
- Import, export, and quick switching of button configurations.

## Button behavior

- Toggle buttons with visible on/off state.
- Separate click, long-press, and right-click actions.
- Keyboard shortcuts for individual buttons.
- Multi-action sequences with delays.
- Context-aware actions based on the active application.

## Live information

- Dynamic values such as time, CPU use, weather, or the current track.
- Progress and cooldown indicators.
- Notification badges and last-run information.

## Presentation and feedback

- Category colors and success/error animations.
- Optional opacity, auto-hide, and edge activation.
- Improved tooltips with shortcuts and action details.
- Optional click sounds or tactile-style animations.
